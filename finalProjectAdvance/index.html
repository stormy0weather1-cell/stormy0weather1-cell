Final Project

This gallery features nine galaxy photographs that showcase swirling nebulae, bright star clusters, and deep-space color gradients. Each image captures a different cosmic scene while keeping the layout easy to browse on phones, tablets, and large screens.

The site is designed to be responsive and accessible, adapting to screen size, reduced-motion preferences, and dark mode settings. Explore the collection to compare how each galaxy photo appears across different device and user preference combinations.
